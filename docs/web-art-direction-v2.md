# Ternline Web Art Direction — V2

Status: active replacement direction, 2026-08-16.

## Objective

Make the catalog feel like a real, established wholesale website: friendly enough to browse, precise enough to purchase from, and visually memorable without generic AI landing-page patterns.

## Top-of-page rules

1. The utility bar contains only operational information: trade program, delivery region, currency, and service hours.
2. The primary header contains the wordmark, real category controls, and order draft. Category controls update the actual catalog filters; no dead navigation.
3. The catalog opening is factual and compact: breadcrumb/context, title, current assortment count, and catalog revision. No oversized manifesto, fake metric card, decorative grid, floating badge, or vague CTA pair.
4. Search, sort, filters, and result count read as one procurement tool, not separate landing-page sections.
5. Use warm flat color fields and hard layout edges for personality. No gradient, glass, glowing shadow, blob, or rounded-card collage.

## Bottom-of-page rules

1. The footer closes the ordering task with facts: MOQ behavior, volume pricing, freight disclosure, browser-local draft behavior, service hours, and delivery region.
2. Footer actions must work: browse all products, set a category filter, open order draft, print catalog, and back to top.
3. Do not invent social channels, newsletter capture, legal pages, account portals, email addresses, certifications, or external support destinations.
4. Avoid slogan stacks and repeated marketing copy. Use concise operational language.

## Visual system

- Reference framing: every desktop web visual uses a native 16:9 landscape viewport (target 1440x810). Never stretch the page into a tall poster or compress the full scroll into one frame.
- Page coverage: use one 16:9 frame for the live top/catalog viewport and, when the footer must be reviewed, a second 16:9 frame captured after scrolling to the bottom.
- Canvas: warm chalk and clean paper.
- Primary: harbor navy and carbon.
- Friendly accent: terracotta used for selected/interactive emphasis.
- Supporting field: pale celadon for catalog context and warm butter for small factual highlights.
- Typography: confident grotesk/system sans with large-but-controlled catalog title and compact mono/uppercase operational labels.
- Geometry: square edges, one-pixel borders, consistent 4px/8px spacing, full-width layout, no floating max-width hero card.
- Motion: quick state feedback only; drawers, filter changes, and add-to-draft confirmations.

## Reference prompt intent

Generate native 16:9 desktop B2B catalog references. The top frame shows the real relationship between utility bar, header, category navigation, compact catalog opening, filtering workspace, and product grid. A separate bottom-scrolled 16:9 frame may show the load-more region and complete operational footer. Generated text is reference-only and must be rebuilt with the deterministic content manifest.
