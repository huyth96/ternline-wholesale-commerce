# Content and Data Manifest

## Locale and commercial rules

- Locale: `en-US`
- Currency: USD
- Prices: wholesale unit prices before tax and freight.
- Quantity rule: quantity must be at least MOQ and must move in the listed order increment.
- Pricing rule: the greatest tier threshold less than or equal to quantity sets the unit price.
- Availability values: `In stock`, `Low stock`, `Made to order`.
- Order drafts and prepared request summaries are stored in the buyer's browser only. The request API validates input and issues a reference but creates no external record.
